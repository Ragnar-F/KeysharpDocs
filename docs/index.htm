Keysharp is a cross-platform C# implementation of the AutoHotkey v2 language. It is in alpha testing; Windows has the broadest coverage. The compatibility target is AutoHotkey v2.1-alpha.32.

Download Keysharp0.0.0.16 for Windows, macOS and Linux

Independent project: Keysharp and KeysharpDocs are not affiliated with, endorsed by, or maintained by the AutoHotkey Foundation or AutoHotkey team. This reference is derived from AutoHotkeyDocs with permission; see licensing and documentation provenance.

Quick Reference

On Ubuntu 24.04, Ubuntu 26.04, and derivatives using those bases, including Pop!_OS 24.04, prefer the Launchpad PPA so apt keeps installed packages updated:

sudo apt install software-properties-common
sudo add-apt-repository ppa:descolada/keysharp
sudo apt update
sudo apt install keysharp

Debian, Pop!_OS 22.04, and other distributions use the release installer. See Linux installation for supported Ubuntu bases, native components and portable migration.
