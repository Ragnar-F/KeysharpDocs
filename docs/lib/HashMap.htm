HashMap Object

class HashMap extends Map

Stores key-value pairs without sorting them before enumeration.

This class is exported by the KS module.

#Import "Ks" { HashMap }

Values := HashMap("red", 1, "green", 2)

Remarks

The enumeration order is unspecified and can change as keys are added or removed. Enumerating a HashMap is faster than enumerating a Map, which sorts its items first.
