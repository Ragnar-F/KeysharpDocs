ObjFree

Releases the pinned copy which StrPtr made of a string which has no memory of its own, such as a literal or the result of an expression.

Released := ObjFree(Pointer)

Parameters

Pointer

Type: Integer

An address which StrPtr returned.

Return Value

Type: Integer (boolean)

This function returns 1 (true) if Pointer was the address of a pinned copy, which it released, or 0 (false) otherwise.

Remarks

A pinned copy stays valid until ObjFree releases it; otherwise it remains allocated until the script exits. What native code writes to it reaches nothing.

The address of a variable's own memory, which StrPtr(MyVar) returns, is not such a copy: that memory belongs to the variable, and ObjFree does nothing to it. The same applies to a StringBuffer's memory.
