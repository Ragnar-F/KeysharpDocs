Keysharp String Functions

This function is exported by the KS module.

ReplaceLineEndings

Text := ReplaceLineEndings(Text , EndOfLine)

Converts every line ending in Text to EndOfLine. If EndOfLine is omitted, `n is used on every platform.

A line ending is `r`n, a lone `r or `n, a form feed, or one of the Unicode characters NEL (U+0085), LINE SEPARATOR (U+2028) and PARAGRAPH SEPARATOR (U+2029).

Example

#Import "Ks" { ReplaceLineEndings }
Text := ReplaceLineEndings("one`r`ntwo`rthree", "`n")   ; "one`ntwo`nthree"
