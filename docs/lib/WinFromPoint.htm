WinFromPoint

Returns the window at a screen position.

HWND := WinFromPoint(X, Y)

Parameters

X, Y

Type: Integer

The point in screen coordinates. If both are omitted, the current cursor position is used.

Return Value

Type: Integer

Returns the window handle at the specified point. The operation can require WindowMonitoring on platforms which protect foreign-window information.
