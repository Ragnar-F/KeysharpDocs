WinMinimizeAll / WinMinimizeAllUndo

Minimizes or unminimizes all windows.

WinMinimizeAll
WinMinimizeAllUndo

WinMinimizeAllUndo() unminimizes minimized top-level windows, preserving their previous normal or maximized state. Windows which are already normal or maximized are left unchanged. Unlike in AutoHotkey, it includes windows minimized individually and does not require a preceding WinMinimizeAll() call. DetectHiddenWindows controls whether hidden windows are included.

Remarks

Windows

WinMinimizeAll() invokes Explorer's Minimize All operation, equivalent to Win+M, which exempts some windows. WinMinimizeAllUndo() skips hung windows.

Linux

Restoring other applications' windows has the same requirements as WinRestore.

macOS

Restoring other applications' windows requires Accessibility permission. Unminimizing leaves native full screen unchanged. Native state transitions have not been verified on macOS.

Error Handling

On macOS, a rejected native operation raises an UnsupportedError. Native behavior is unverified.

Related

WinRestore, WinMinimize, GroupAdd

Examples

Minimizes all windows for 1 second and unminimizes them.

WinMinimizeAll
Sleep 1000
